FEATURES

游戏特色

经典俯视角坦克战斗，加入现代 Roguelite 成长与策略构筑。

⚔

硬核攻防

玩家坦克与我方基地只有一条命，敌方基地持续生产坦克，必须且战且退、绕圈射击。

⚙

装备构筑

引擎、轴承、主炮、炮弹、装甲、护盾、特种装置自由搭配，打造专属坦克与基地。

↻

Meta 成长

击败精英与 BOSS 获得黑匣，永久强化坦克与基地属性，越战越强。

🎲

Roguelite 循环

每次战役携带有限蓝图进入战术背包，金币、模组、装备在战役结束后清零，策略选择决定生死。

GAME LOOP

核心循环

Meta 成长 → 构筑循环 → 战斗循环，在失败与胜利中不断变强。

01

Meta 循环（指挥部）

战役结束后回到 Meta 循环。消耗战斗中获得的「黑匣」永久提升坦克与基地的基础属性，并从蓝图库中挑选下一次战役的战术背包。

  • 黑匣永久成长
  • 战术背包配置
  • 资产重置与传承
→
02

构筑循环（基地）

进入战斗前进行后勤决策：维修基地与坦克、使用蓝图制造装备、消耗模组与金币升阶/强化装备、装配到坦克与基地槽位。

  • 装备制造与回收
  • 装备升阶 / 强化
  • 坦克 / 基地装配
→
03

战斗循环（战场）

在随机生成的地图中抵御多波攻势，摧毁敌方基地与坦克，保卫我方基地。拾取金币、模组与道具，为下一段循环积累资源。

  • 多关卡多波次
  • 基地补给与维修
  • 道具与一次性武器
GEAR SYSTEM

装备系统

蓝图决定潜力，金币铸造装备，模组强化属性。稀有度从白到金，构筑没有唯一解。

坦克装备槽

引擎提升坦克移动速度
轴承提升炮塔旋转速度
主炮提升炮弹速度与射击频率
炮弹提升炮弹伤害与射程
装甲减少坦克受到的伤害
护盾提供可激活的能量护盾
潜渡 / 隐身 / 雷达特种装备
